# Plant Swap Shelf

## How to run

First, you need to configure the .env files in both projects. After, start 2 terminals and run the following commands:

Terminal 1:

```
cd S2bStarterExpress
npm install
npm run dev
```

Terminal 2:

```
cd S2bStarterSveltekit
npm install
npm run dev
```

The svelte application is available now on port 5173. The API is available on port 3001.

## Questions

**1. Where is it decided?**

The database connection URI is defined in `S2bStarterExpress/.env`, and is accessed using `mongoose.connect()` in `S2bStarterExpress/index.js`. The svelte application does not directly access the db.
The collection is named `plants`, determined by the mdoel name in `S2bStarterExpress/models/Plant.js`, mongoose automatically makes the name plural and lowercase.

**2. How the filter works:**

1. SvelteKit calls `load({url})`
2. `load()` checks the light level against the 3 known values, and calls `fetchPlants()` with the light level. 
3. `fetchPlants()` makes a request to the API, requesting all plants of the specified light level. 
4. `plantData.getAll()` is used to fetch all the plants, with the light level passed as an argument
5. `Plant.find()` is used with the light level filter to return the required plants from MongoDB.
6. The call stack returns, with SvelteKit rendering the results from `load()`.

**3. What is a plant's id?**

The id is a 24 character hex string stored as `_id` in the database. Express does not directly create the ID, It is automatically generated by MongoDB when the plant is inserted using `Plant.create()`. Express sends the same value as `id` in the JSON, and it is also the same value used in `/shelf/<id>`. In SvelteKit, `fetchPlant(params.id)` was used to get an individual plant.
